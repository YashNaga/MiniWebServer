**Mini Web Server in C**

- Just a mini web server as a library for me to practice C with

- To test simply compile with test.c and Server.c e.g

``
gcc test.c Server.c -o output.exe
``

and run the output.

The default port is 9090 but this can be changed in the test.c main function
